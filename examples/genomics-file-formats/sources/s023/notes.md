# Ensembl Retrieving sequences

## Appraisal for this packet

- **Fit — Strong:** fills CDS/transcript vocabulary without a biology course.
- **Authority — Strong:** primary Ensembl database tutorial.
- **Support — Strong:** selected definitions are explicit.
- **Currency — Strong:** archived release context.
- **Clarity — Adequate:** needs a simple original diagram rather than browser screenshots.

## Inspected source statements

- **Transcript sequence:** Ensembl transcripts are splice variants that can be coding or noncoding. A coding transcript includes untranslated regions and a coding sequence (CDS).
- **Exons and Introns / cDNA and protein:** different views distinguish UTR, CDS, introns, flanking sequence and protein.
- These categories distinguish coding sequence from the full transcript and exon from necessarily protein-coding sequence.
- This tutorial does not define every GTF/CDS convention; use the declared file producer's rules for stop codon treatment and phase.

## Pedagogical inference and limits

Explain an annotation feature as a labeled region on a reference sequence, and CDS as the part encoding protein. Use modest original examples without assuming that every exon codes for protein. No full splicing mechanism is required for the target validity judgments.
