# NHGRI Talking Glossary: selected foundational definitions

## Inspected source statements

Selected **Definition** sections:
- [DNA](https://www.genome.gov/genetics-glossary/Deoxyribonucleic-Acid-DNA): genetic-information molecule with A/C/G/T bases and complementary strands.
- [DNA Sequencing](https://www.genome.gov/genetics-glossary/DNA-Sequencing): determining base order.
- [Reference sequence](https://www.genome.gov/genetics-glossary/Human-Genome-Reference-Sequence): accepted representation used for comparison, not one person's entire genome.
- [Chromosome](https://www.genome.gov/genetics-glossary/Chromosome): DNA-containing structure carrying genomic information.
- [Protein](https://www.genome.gov/genetics-glossary/Protein): one or more amino-acid chains.
- [Exon](https://www.genome.gov/genetics-glossary/Exon): genomic region retained in mRNA; coding and noncoding exons exist.
- [Codon](https://www.genome.gov/genetics-glossary/Codon): three-base information unit encoding amino acid or stop.
- [Allele](https://www.genome.gov/genetics-glossary/Allele): alternative DNA version at a location.
- [Genotype](https://www.genome.gov/genetics-glossary/genotype): variant constitution at a location, represented symbolically or by sequence.
The Exon narration oversimplifies coding status; use the qualified definition. Human diploid examples do not imply every sample/locus has ploidy two.

## Pedagogical inference and limits

Teach only terminology needed to read format examples. Reference assembly identity, sequence identifiers and data provenance require further context; these glossary definitions do not validate a particular dataset.
