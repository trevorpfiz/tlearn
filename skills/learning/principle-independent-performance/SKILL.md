# Independent performance

Check the target capability on a fresh task under explicit assistance conditions. Describe only the performance observed.

**Why:** Finishing a section, following a solution, and independently applying an idea supply different evidence. An instructional graph does not establish a learner's knowledge state.

**Apply:**

- Define the final demonstration before writing the lesson. Use a new instance requiring the target action; change meaningful conditions when transfer is part of the goal.
- Remove worked steps and answer-revealing method cues. State allowed resources: authentic documentation or a calculator may be appropriate without making the task assisted by a solution.
- Keep optional help available. Record help or solution reveals separately from an independent attempt; use a fresh task to check independence afterward.
- Provide checked answers for deterministic tasks and a concrete rubric with acceptable alternatives for reasoning. Use transparent self-checking when the HTML cannot reliably judge the response. Do not equate string matching or a learner's self-report with verified scientific reasoning.
- Permit one-click **Mark complete** and reopening for every section. Do not lock navigation behind a quiz or infer mastery from a checkbox.
- Keep claims local: “solved this task without hints” is stronger evidence than “finished,” but neither establishes universal mastery. Long-term retention requires a later check; ongoing spaced review remains optional.

**Check:** Does each target capability have a fresh demonstration? Can the record distinguish completion, solution-assisted performance, and an unaided response, with the basis of any judgment clear?

**Sources:** [The Math Academy Way](https://www.justinmath.com/books/), mastery learning; [Doignon and Falmagne (2015)](https://arxiv.org/abs/1511.06757), Knowledge Space Theory. See [evidence and tlearn's adaptations](../design-learning/references/learning-evidence.md#independent-performance).
